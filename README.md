# digital-forensic-practice
В этом документе собраны решения различных заданий на тему цифровой форензики, которые демонстрируют навыки комплексного анализа артефактов операционных систем, исследования сетевого трафика и восстановления удаленной информации в рамках расследования компьютерных инцидентов для судебной практики.
